# 影游快启 · Windows 7 专用版

这是专门为 **Windows 7** 用户打包的版本，与主版本完全隔离，互不干扰；在 Win10 / Win11 上同样可以运行。

> **源码已随主仓库发布**：本版完整源码位于同一仓库的 `launchplay-win7/` 目录（含 `src/`、`package.json`、图标与构建工具），可自行构建或修改；Release 里的安装包与解压包就是这份源码构建出来的。构建命令见主仓库 README「从源码构建 → Windows 7 专用版」。

## 为什么需要这个版本

主版本基于 Electron 38，从 Electron 23 起官方已停止支持 Windows 7，因此主版本在 Win7 上无法启动。
本版本基于 **Electron 22.3.27**（最后一个支持 Win7 的主版本），可在 Win7 上正常运行。

## 选哪个文件

| 文件 | 用法 | 适合 |
| --- | --- | --- |
| `LaunchPlay-1.0.0-windows-x64-win7-setup.exe`（约 62 MB）**推荐** | 双击安装，自动创建「影游快启 Win7」桌面快捷方式 | 长期使用，启动最快 |
| `LaunchPlay-1.0.0-windows-x64-win7-portable.zip`（约 85 MB） | 解压到任意文件夹，双击里面的 `LaunchPlayWin7.exe` | 不想装到系统、临时使用 |

> 早期提供的单文件 `LaunchPlay-1.0.0-windows-x64-win7.exe` 自解压版，在部分系统上启动后会立即退出，已停用，请改用上面两个文件。

## 运行环境要求

- **Windows 7 SP1（64 位）** —— 必须已安装 SP1；未装 SP1 的 RTM 版本无法运行。
- 建议先安装以下两个系统更新（精简版 / Ghost 版 Win7 常见缺失，缺了会起不来）：
  - **KB2533623**
  - **KB2670838**
- 无需安装 VC++ 运行库（已随程序打包）。
- Win10 / Win11 不需要以上补丁，可直接运行。

## 使用方法

1. **安装版**：双击 setup，按提示完成安装，之后从桌面快捷方式启动。
2. **免安装版**：把 zip 解压到一个固定文件夹（不要直接在压缩包里双击），然后运行 `LaunchPlayWin7.exe`。
3. 程序配置、图标缓存等数据保存在 `LaunchPlayWin7Data` 文件夹（解压版在 exe 同级），备份时把这个文件夹一起拷走即可保留设置。

## 安装向导卡住怎么办

如果第一页提示「**已经存在一个安装到当前用户的安装……即将重新安装/升级**」，且点「下一步」后**安装按钮是灰的**，按下面顺序处理：

1. **先关掉正在运行的程序**：打开任务管理器，结束所有 `LaunchPlayWin7.exe` 进程。程序正在运行时文件被占用，安装按钮会被禁用——这是最常见的原因。
2. 重新运行 setup，在第一页改选 **「为使用这台电脑的任何人安装（所有用户）」**，一般即可正常继续。
3. 仍然不行，先卸载旧版：控制面板 → 程序和功能 → `LaunchPlayWin7 1.0.0` → 卸载，再重新双击 setup 安装。
4. 如果卸载项指向一个**已经被删掉的临时文件夹**（卸载时提示找不到文件），说明注册表里留了一条失效的安装记录。请让熟悉电脑的人删除该记录后重装，或**直接改用免安装 zip 版**绕开安装向导（推荐，最省事）。

> 注册表记录位置（仅第 4 步需要，删除 HKLM 项要管理员权限）：
> `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\` 与 `HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall\`，找 `DisplayName` 为 `LaunchPlayWin7 1.0.0` 的项。

> 说明：这条提示只在**曾经装过本程序**的电脑上出现，全新电脑第一次安装不会遇到。

## 与主版本共存

- 本版本使用独立的 AUMID（`com.launchplay.desktop.win7`）和独立数据目录（`LaunchPlayWin7Data`）。
- 两个版本可以装在同一台电脑，配置不会互相覆盖；桌面快捷方式名分别为「影游快启」和「影游快启 Win7」。

## 本版功能（已与主版本同步）

Win7 专用版与主版本**功能完全一致**，只是换成 Electron 22.3.27 内核、独立 appId 与数据目录。截至 2026-11-18 已同步：

- **界面**：左上角带字 logo、时间后的天气；全仓统一称「影音软件」，不含任何具体影音平台名。
- **天气**：设置里「先选省份、再选城市」，内置全国 34 个省级行政区 / 369 个城市编码，离线可选；实况走中国天气网。
- **手机遥控**：导航键任何时候都只做导航（不再变成音量/快进）；打开程序自动跳到播放遥控卡片；大字版 / 标准版一键等比切换；最多 4 个自定义万能键。
- **实用工具**：定时关机、家长守护模式（密码、强制休息、答题解锁、自定义题库）。
- **家长守护计时**：按现实时间累计并落盘，重启不清零、关机期间不计时、防改系统时间。
- **轻量加固**：可选开关 —— 禁用任务管理器与 Win 键、看门狗自动拉起、失焦抢回；**不依赖 Windows Kiosk / Shell Launcher**，所以 Win7 同样可用，且可随关闭守护或退出软件恢复。
- **手机遥控键鼠注入已适配 Win7**：Win7 SP1 默认只有 PowerShell 2.0 + .NET 3.5，注入脚本不再使用 PowerShell 3.0 / .NET 4.0 才有的 API，鼠标模拟、中文输入、组合键均可正常工作。若系统未启用 .NET Framework 3.5 导致组件无法编译，手机页面会显示具体原因和 PowerShell 版本，便于排查。

> Windows 官方 Assigned Access 单应用 Kiosk 只支持 UWP / Edge（不支持 Win32 桌面程序），Shell Launcher 又仅限企业版 / 教育版，Win7 两者都没有。因此「不能切回桌面、不能强制关掉本软件」在本版同样采用轻量加固方案，能力边界与主版本一致：`Ctrl+Alt+Del`、长按电源键、管理员强制结束属于系统级手段，任何用户态应用都无法阻止。

题库格式见主项目 README 的「自定义题库」章节，样本文件在本目录 `docs/questions.sample.json`；设置里也有「导入题库 / 导出样本题库」。

## 已知限制

- **应用内自动更新不可用**：关于面板会显示「打开下载页」按钮，点击可前往 GitHub 手动下载新版，属正常现象。
- 轻量加固中的看门狗是普通用户态进程，任务管理器同样可以结束它；它的作用是让误关后自动回来，不是防系统级强杀。
- Electron 22 已于 2023 年停止安全维护，仅建议在确实无法升级系统的 Win7 机器上使用；能升级到 Win10/11 的用户请使用主版本。
